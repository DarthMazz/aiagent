# Kiro固有プロンプト仕様

Kiro エージェントに特有の動作・ステアリング・制約を定義します。

## エージェントフック

Kiro のエージェントフックを活用し、コード変更後に自動的に以下を実行する:
- Lint チェック: `uv run ruff check .`
- テスト実行: `uv run pytest`

## ステアリングファイル

`.kiro/steering/` にプロジェクト固有のコンテキストを配置する:
- `product.md` — プロダクトの目的・ターゲットユーザー・主要機能
- `tech.md` — 技術スタック・インフラ・開発環境のセットアップ
- `structure.md` — プロジェクト構造・主要コンポーネント・命名規則

## スペックファイル

機能実装前に `.kiro/specs/{feature}/` に以下を作成する:
- `requirements.md` — ユーザーストーリー・受け入れ条件
- `design.md` — アーキテクチャ設計・DDDモデル
- `tasks.md` — 実装タスクリスト（TDD順序を意識）

## 応答スタイル

- タスク完了後に簡潔なサマリーを提示する
- 大きな変更はスペックを先に作成・確認してから実装する
- ファイル変更前に現在の状態を確認し、影響範囲を明示する

## カスタムルール追加

`.kiro/rules.md` にプロジェクト固有ルールを追加することで、このファイルの内容を上書き・拡張できる。
